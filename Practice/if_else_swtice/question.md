Since you're learning Go (Golang), here are some easy if-else and switch practice problems. I used simple English and started with easy questions.

## If-Else Problems
1. Even or Odd

Ask the user for a number.

If the number is even, print "Even".

Otherwise, print "Odd".

2. Positive, Negative, or Zero

Ask the user for a number.

If the number is greater than 0, print "Positive".

If the number is less than 0, print "Negative".

Otherwise, print "Zero".

3. Pass or Fail

Ask the user for marks.

If marks are 40 or more, print "Pass".

Otherwise, print "Fail".

4. Bigger Number

Ask the user for two numbers.

Print the bigger number.

5. Age Check

Ask the user for age.

If age is 18 or more, print "You can vote."

Otherwise, print "You cannot vote."

6. Largest of Three Numbers

Ask the user for three numbers.

Print the largest number.

7. Discount

Ask the user for a shopping amount.

If the amount is 1000 or more, print "10% Discount".

Otherwise, print "No Discount".

8. Divisible by 5

Ask the user for a number.

If the number is divisible by 5, print "Yes".

Otherwise, print "No".

Switch Case Problems
1. Day Name

Ask the user for a number (1 to 7).

Print:

1 → Monday

2 → Tuesday

3 → Wednesday

4 → Thursday

5 → Friday

6 → Saturday

7 → Sunday

If the number is not 1-7, print "Invalid Day".

2. Grade

Ask the user for a grade letter.

Print:

A → Excellent

B → Good

C → Average

D → Poor

F → Fail

3. Calculator

Ask the user for:

first number

second number

operator (+, -, *, /)

Use switch to calculate and print the answer.

4. Month Name

Ask the user for a month number (1-12).

Print the month name.

Example:

1 → January

2 → February

12 → December

5. Traffic Light

Ask the user for a color.

Print:

"red" → Stop

"yellow" → Wait

"green" → Go

Any other color → Unknown Color

Challenge Problems (Mix if-else and switch)
Challenge 1: Leap Year

Ask the user for a year.

If it is a leap year, print "Leap Year".

Otherwise, print "Not Leap Year".

Challenge 2: Simple Login

Ask the user for a password.

If the password is "golang123", print "Login Success".

Otherwise, print "Wrong Password".

Challenge 3: Number to Word

Ask the user for a number (0-5).

Use switch to print:

0 → Zero

1 → One

2 → Two

3 → Three

4 → Four

5 → Five

Example Input and Output

Input

Enter a number: 8

Output

Even

These problems are arranged from easy to slightly harder, which is good practice for learning Go's if, else if, else, and switch statement
