# Go Functions Practice Problems

## Easy Problems

### 1. Print Hello

Create a function called `hello()` that prints:

Hello, World!

---

### 2. Add Two Numbers

Create a function `add(a, b int)` that takes two numbers and prints their sum.

Example:

Input: 5, 3  
Output: 8

---

### 3. Even or Odd

Create a function that takes a number and prints whether it is **Even** or **Odd**.

Function idea:

`func evenOdd(num int)`

Example:

Input: 10  
Output: Even

---

### 4. Find the Bigger Number

Create a function that takes two numbers and returns the bigger number.

Example:

Input: 10, 20  
Output: 20

---

### 5. Square of a Number

Create a function that takes a number and returns its square.

Example:

Input: 5  
Output: 25

---

# Medium Problems

### 6. Positive, Negative, or Zero

Create a function that takes a number and prints:

- Positive
- Negative
- Zero

Example:

Input: -5  
Output: Negative

---

### 7. Calculator Function

Create a function that takes:

- Two numbers
- An operator (`+`, `-`, `*`, `/`)

Use `switch` inside the function to calculate the answer.

Function idea:

`func calculator(a, b float64, operator string)`

---

### 8. Largest of Three Numbers

Create a function that takes three numbers and returns the largest number.

Example:

Input: 10, 25, 15  
Output: 25

---

### 9. Leap Year Function

Create a function that takes a year and returns `true` if it is a leap year. Otherwise, return `false`.

Function idea:

`func isLeapYear(year int) bool`

Example:

Input: 2024  
Output: true

---

### 10. Factorial

Create a function that takes a number and returns its factorial.

Example:

Input: 5  
Output: 120

Because:

5 × 4 × 3 × 2 × 1 = 120

> You may need to learn loops for this problem.

---

# Challenge Problems

### 11. Check Password

Create a function:

`func checkPassword(password string)`

If the password is `golang123`, print:

Login Successful

Otherwise, print:

Wrong Password

---

### 12. Count Even Numbers

Create a function that takes a list of numbers and counts how many numbers are even.

Example:

Input: 1, 2, 3, 4, 5, 6  
Output: 3

---

### 13. Find the Smallest Number

Create a function that takes three numbers and returns the smallest number.

Example:

Input: 10, 5, 20  
Output: 5

---

### 14. Check Vowel

Create a function that takes a letter and checks if it is a vowel.

Vowels are:

`a, e, i, o, u`

Example:

Input: a  
Output: Vowel

---

### 15. Simple Grade Checker

Create a function that takes marks and returns a grade.

Rules:

- 80 or more → A
- 70 or more → B
- 60 or more → C
- 50 or more → D
- Less than 50 → F

---

1 → 2 → 3 → 4 → 5 → 6 → 7
